# OBLISK Windows EXE Build Guide

## Overview

This document explains how to build OBLISK as a production-grade Windows executable (`.exe`) using Nuitka, which compiles Python code to optimized C/C++.

## Quick Reference

| Method | Command | Output |
|--------|---------|--------|
| **Local Build** | `python build_oblisk.py` | `./dist/OBLISK.exe` |
| **Custom Version** | `python build_oblisk.py --version 3.0.1` | `./dist/OBLISK.exe` |
| **Onefile Mode** | `python build_oblisk.py --mode onefile` | `./dist/OBLISK.exe` (single file) |
| **CI/CD (GitHub)** | Push tag `v3.0.1` | Automated build + Release |

## Prerequisites

### Windows Requirements
- **Windows 7 or later**
- **Python 3.8+** (3.11 recommended for best performance)
- **C/C++ compiler** (MSVC, MinGW, or Clang) - Nuitka requires one
  - Easiest: Install "Desktop development with C++" from Visual Studio

### Python Packages
```bash
pip install nuitka
pip install -r requirements.txt  # OBLISK dependencies
```

## Local Build

### 1. Install Nuitka

```bash
pip install --upgrade pip
pip install nuitka
```

Verify installation:

```bash
python -m nuitka --version
```

### 2. Install OBLISK Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run Build Script

```bash
python build_oblisk.py
```

**Output:**
- `./dist/OBLISK.exe` - Main executable
- `./dist/OBLISK-Portable-3.0.0/` - Portable bundle

### 4. Test the EXE

```powershell
.\dist\OBLISK.exe --help
.\dist\OBLISK.exe --version
.\dist\OBLISK.exe start
```

## Advanced Build Options

### Custom Version

```bash
python build_oblisk.py --version 3.0.1
```

### Standalone vs Onefile Mode

**Standalone Mode (default):**
```bash
python build_oblisk.py --mode standalone
```
- Creates: `OBLISK.exe` + supporting files in `dist/`
- Pros: Faster startup, easier debugging
- Cons: Slightly larger total size

**Onefile Mode:**
```bash
python build_oblisk.py --mode onefile
```
- Creates: Single `OBLISK.exe` (self-extracting)
- Pros: Single file distribution
- Cons: Slightly slower startup (first run unpacks)

### Hide Console Window

```bash
python build_oblisk.py --no-console
```

Useful for daemon mode or when running as a service.

### Custom Output Directory

```bash
python build_oblisk.py --output C:\builds\oblisk
```

## Build Output Structure

### Standalone Mode

```
dist/
├── OBLISK.exe                           # Main executable
├── OBLISK/                             # Runtime files
├── config/                             # Config files (if present)
├── examples/                           # Examples (if present)
└── OBLISK-Portable-3.0.0/              # Portable bundle
    ├── OBLISK.exe
    ├── config/
    └── README.txt
```

### Onefile Mode

```
dist/
├── OBLISK.exe                           # Single executable
└── OBLISK-Portable-3.0.0/              # Portable bundle (optional)
    └── OBLISK.exe
```

## GitHub Actions CI/CD

Automatic builds are triggered by:

### Method 1: Git Tag (Recommended)

```bash
git tag v3.0.1
git push --tags
```

This will:
1. Trigger the GitHub Actions workflow
2. Build `OBLISK.exe` v3.0.1
3. Create a GitHub Release with the EXE as an attachment

### Method 2: Manual Workflow Dispatch

Go to GitHub:
1. **Actions** → **Build OBLISK Windows EXE**
2. **Run workflow**
3. Specify version and build mode

### Method 3: Push to Main

Any push to `main` triggers a build (but no release is created).

## Performance

### Build Time
- **Standalone**: 3-5 minutes (first build with dependencies)
- **Onefile**: 4-7 minutes (adds self-extractor overhead)
- **Subsequent builds**: 1-2 minutes (caching)

### Runtime Performance
- **Startup time**: < 2 seconds
- **Memory usage**: ~100-200 MB baseline
- **CPU**: Minimal idle overhead

### Binary Size
- **Standalone**: 40-80 MB (depending on dependencies)
- **Onefile**: 50-90 MB (includes self-extractor)

## Troubleshooting

### Issue: "nuitka not found"

**Solution:**
```bash
pip install nuitka
```

### Issue: "CC compiler not found"

**Solution:**
Nuitka requires a C/C++ compiler. Install Visual Studio Community:
1. Download from [microsoft.com/visualstudio](https://microsoft.com/visualstudio)
2. Select "Desktop development with C++"
3. Install MSVC compiler
4. Restart build

Alternatively, use MinGW:
```bash
pip install nuitka[mingw]
```

### Issue: "Out of memory during build"

**Solution:**
Nuitka is memory-intensive. Try:
1. Close other applications
2. Use onefile mode (slightly less memory)
3. Increase system RAM
4. Use `--jobs` flag to limit parallelization:
   ```bash
   # Edit build_oblisk.py, add: --jobs=1
   ```

### Issue: Antivirus flags EXE as malware

**Solution:**
This is common for EXEs generated by runtime compilers. To fix:
1. Submit to your antivirus vendor for whitelisting
2. Sign the EXE with a code-signing certificate
3. Distribute via official channels (GitHub Releases)

### Issue: EXE fails to run on target machine

**Possible causes:**
- Missing Python 3.8+ compatibility
- Missing C++ runtime library on target
- File permissions issue

**Solutions:**
1. Test on clean Windows VM
2. Ensure target has .NET Framework 4.5+ (usually pre-installed)
3. Copy entire `dist/OBLISK/` folder with EXE
4. Use standalone mode (not onefile) for better compatibility

## Security Considerations

### Code Signing

For production distribution, sign the EXE:

```powershell
# Requires code-signing certificate
$cert = Get-ChildItem cert:\CurrentUser\My | Where-Object {$_.Subject -like "*Your Company*"}
Set-AuthenticodeSignature -FilePath "dist\OBLISK.exe" -Certificate $cert
```

### Secure Distribution

1. **Use HTTPS**: Always distribute via secure channels
2. **Verify signatures**: Include checksum/signature in release notes
3. **Update mechanism**: Implement auto-update with signature verification
4. **Disable console**: Use `--no-console` for daemon mode
